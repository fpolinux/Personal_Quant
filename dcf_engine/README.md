How to use
===============

To use this dcf engine, first build a yaml config file by copying default_yaml.yaml and tweaking it for your stock.
Then, simply run: monte_carlo_generic.py example_stock.yaml and a DCF, calculated as a distribution will result. 

Historical examples of some of the DCFs I have run are in the sample configs folder for those interested in how I run these DCFs. Some have notes on where I have pulled my assumptions from. Often, this is as simple as CapIQ, or calculated manually from earnings reports.
